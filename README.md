# 🛒 E-Store

> A responsive e-commerce website built with HTML, CSS, JavaScript, and Bootstrap, featuring product browsing, authentication, cart management, and checkout pages.

## 📋 Overview

**E-Store** is a responsive e-commerce web application created to simulate a modern online shopping experience.

The project focuses on building a complete frontend shopping flow, from the landing page and user authentication to viewing products, managing a shopping cart, and reaching the checkout stage.

The project was built to strengthen my understanding of frontend development, responsive design, UI structure, and client-side JavaScript.

---

* 🏠 **Landing Page**

## 🚀 Getting Started

### Prerequisites

You only need a modern web browser to run the project.

### Installation

Clone the repository:

```bash
git clone https://github.com/Famashrafs/e-store.git
```

Navigate into the project:

```bash
cd e-store
```

Open the project in your preferred development environment.

If the project uses a local development server, run it according to your environment.
